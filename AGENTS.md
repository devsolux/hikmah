# Hikmah contributor instructions

Read README.md, docs/ARCHITECTURE.md, and docs/SOURCES.md before changing behavior.
The product is Hikmah / hikmah / 1.0.0 and supports Claude and ChatGPT only. One
coordinator is not one perspective: preserve the full 99-lens DMG source catalog,
peer-blind first positions, genuine cross-examination, and dissent-preserving synthesis.

## Ownership

- project.json: product identity, host support, version, and attribution.
- agents/hikmah.md: one host coordinator, briefing, semantic panel choice, and recommendation.
- personas/: 99 authored human-level methods, blind spots, contracts, and own-source bindings.
- config/panels.json: canonical presets, typed method relations, and local reference records.
- sources/hikmah.md: the source table (No., DMG, Meaning, Vision core). Never silently rewrite
  or reinterpret it; any deliberate change rebinds all hashes and is documented.
- scripts/contracts.py: one strict JSON/frontmatter parser and shared validation primitives.
- scripts/deliberation.py: resource binding, deterministic routing, balanced reviews, isolated
  request compilation, authorized API transport, response validation, the objection ledger,
  and the offline packet audit.
- scripts/project.py: validated packages, source synchronization, reproducibility, and safe cleanup.
- Makefile: thin offline interface. dist/: generated output, not editable source.
- .claude-plugin/, .agents/, plugins/: the committed public `devsolux-hikmah` marketplace
  (install ID `hikmah@devsolux-hikmah`). Generated by make sync-marketplace; never hand-edit.

Use DMG labels as analytical lens names only. No impersonation of Allah, divine
embodiment, revelation, religious rulings, or perfect knowledge. Distinguish exact
source content from editorial adaptations. One table remains one source, regardless
of its number of row references. Relations are between human applications, not divine Names.
Do not fabricate verses, translations, scholarly endorsements, human witnesses, or emotions.

Only the coordinator synthesizes. Seats do not coordinate, browse, or execute user actions.
Keep brief, catalog, methods, and snapshot roots immutable. Round 1 never sees peers,
relation appendices, expected opponents, or the coordinator's preferred option. Later
requests receive deterministic review-neighborhood views of frozen snapshots; the
packet retains every validated contribution and objection, including omitted-from-view
positions. Do not add another AI summarizer, hidden truncation, service, or provider.

Use Python 3.11+ standard library. Builds/tests/detection/planning must remain offline.
Keep secrets, access-control decisions, hard constraints, and action authority outside
model control. Do not follow symlinks, overwrite unknown output, install, publish,
deploy, or issue billable requests without explicit authorization. Preserve the license.

## Verification

After relation/reference edits run make sync-personas; preserve authored method text.
After any source edit run make sync-marketplace. Normal build/check must fail on stale
appendices or a stale committed marketplace, not hide them. Keep version 1.0.0.
Run make check, make build, make verify, and a fresh-archive rebuild. Preserve negative
security tests when adapting content-specific fixtures. Add regressions for every fixed
bug, source fidelity, 99-seat scaling, bounded contexts, failed seats, stale/mixed
snapshots, and source/evidence namespaces. Do not weaken tests merely to pass.
Record live desktop/API/quality tests as unrun unless they actually executed.
