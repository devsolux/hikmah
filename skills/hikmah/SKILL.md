# Hikmah — decision deliberation

**Hikmah** 1.0.0 is decision-deliberation software; nothing in it speaks for Allah.
The 99 supplied DMG labels name human-level analytical instruments,
not divine entities. No divine voice, revelation, religious ruling, or infallibility.

Read `references/coordinator.md` for the single coordinator protocol and `references/host.md`
for the active surface. The current conversation coordinates; do not create a second
synthesizer or an extra decision authority.

Begin with a frozen brief: decision, constraints, evidence, reversibility, deadline,
and stable option IDs. Then use `references/catalog.md` and `references/panels.json`
to select relevant, deliberately different lenses. Load selected resources progressively,
not all 99 complete profiles by default. Preserve an explicit full-catalog request.

Every lens has an authored method, blind spots, a structured contract, exact source
binding, and conditional relationships. Source rows are labels from one supplied
table, not verified doctrine or independent decision evidence. `references/sources/hikmah.md`
preserves the original. Never silently correct, extend, or spiritualize its content.

Read `references/DELIBERATION_LOGIC.md` before execution. Maintain all three rounds:
independent first positions, assigned direct cross-examination, and mandatory replies
to received objections. Deterministic neighborhood views preserve complete snapshots
in the packet; no AI compression or silent truncation is authorized.

Use only genuinely isolated host tasks or the explicit optional API path documented
in `references/RUNTIME.md`. `scripts/deliberation.py detect`, `plan`, and `audit` are offline.
A billable run requires actual model IDs, user-approved providers, `--allow-network`,
and `--confirm-data-sharing`. Never discover credentials from local files, escalate a
budget, or infer API access from a desktop session. No extra MCP server is needed.

No isolation means return a brief, panel plan, and execution blocker. A rehearsal
must be labeled as such and cannot claim independent personas actually ran.

Produce one advisory recommendation that preserves evidence, dissent, unanswered
questions, coverage limitations, kill criteria, and the next concrete action. Use
third-person analytical language, not “Allah has decided.” The user retains authority.
Follow the host's governing instructions and explicit user directions over this skill.
