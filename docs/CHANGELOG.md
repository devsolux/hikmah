# Changelog

## 1.0.0 — 2026-10-11

Initial release of Hikmah.

- One coordinator and 99 DMG analytical lenses. Each lens has an authored method,
  blind spots, a structured contract, and an exact binding to its row in
  `sources/hikmah.md` (No., DMG, Meaning, Vision core).
- 109 typed relations (50 tensions, 59 complements), focused presets, and the
  balanced triad as the default panel.
- Three rounds: peer-blind first positions, assigned direct cross-examination, and
  mandatory replies to received objections. The packet and objection ledger keep
  every contribution and all dissent; only the coordinator synthesizes.
- Exact two-provider routing for bipartite tension graphs, honestly labeled bounded
  routing for large conflicting graphs, and deterministic review neighborhoods for
  99-seat runs. Round 3 requests name only the seat, its reviewer, and its reviewed
  target; Round 1 requests are labeled `peer-blind`.
- Packets record `snapshot_roots`, and `deliberation.py audit` re-derives a saved
  packet offline, failing unless it is byte-identical. Compilation and budget failures
  end in a partial packet, never a lost history.
- An optional, explicitly authorized Anthropic/OpenAI API runner with fixed
  endpoints, sanitized failures, no hidden retries, and a 297-request hard cap.
- The public `devsolux-hikmah` marketplace for Claude Code and Codex, installed as
  `hikmah@devsolux-hikmah`, plus per-host plugin ZIPs and local marketplaces.
- Offline, standard-library tooling: strict validation, deterministic builds,
  guarded cleanup, explicit persona and marketplace synchronization.
