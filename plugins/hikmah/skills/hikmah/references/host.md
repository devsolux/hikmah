# Host adapters

This package is shared by Claude and ChatGPT/Codex surfaces. Follow only the section for the surface that is actually running; neither section implies the other host is available.

## Claude adapter

Use the one active Claude conversation as coordinator. Load the packaged coordinator.md
protocol, selected DMG methods, and catalog progressively. Never adopt a divine
voice or treat a persona as a divine entity.

The Claude package is a skill plugin, not an MCP bundle. Use the supported custom
plugin or marketplace installation flow available in the actual Claude surface; in
Claude Code the public marketplace installs it as `hikmah@devsolux-hikmah`.
No implicit Claude Code registration, native agent creation, or shell permission is
claimed. An installed profile is a resource, not proof that an isolated worker ran.

For full deliberation, verify peer-free first-position execution and structural
contracts using actually exposed authorized tools. Otherwise use the optional Python
runtime only after explicit API/network/data-sharing consent, or return a plan and
capability blocker. Do not fabricate an independent multi-persona run in one context.

The active coordinator produces one advisory recommendation from the full packet.
Keep missing coverage, unresolved dissent, source limitations, and next action visible.
Do not infer Anthropic API configuration from a Claude desktop subscription or session.

catalog, and selected DMG resources. Never speak as Allah or produce a divine voice,
religious ruling, or claim of infallibility.

`devsolux-hikmah` marketplace (.agents/plugins/marketplace.json) as
`hikmah@devsolux-hikmah`; the local marketplace archive has the same layout. Use
supported local-plugin ChatGPT Desktop Work/Codex surfaces and actual workspace

are separate capabilities. Do not infer one from another or silently modify a
personal marketplace, credential file, or another installed plugin.

Full deliberation requires real peer-free tasks honoring the contracts, or the
optional Python API runner after explicit network and data-sharing authorization.
No native task bridge or additional MCP server is provided. Without that capability,
return a brief and blocker, not fictitious independent member participation.

missing seats/reviews, kill criteria, and the next concrete action. Counts are only
advisory. Do not infer OpenAI API configuration from a ChatGPT desktop session.
